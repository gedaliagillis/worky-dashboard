# Worky Dashboard

Fully editable job search dashboard with GitHub auto-save.

**Live URL:** https://gedaliagillis.github.io/worky-dashboard/

## Features

- ✅ **Edit directly on dashboard** - Click Edit on any lead
- ✅ **Auto-save to GitHub** - Changes commit automatically
- ✅ **Never lose data** - Everything stored in Git
- ✅ **Add/delete leads** - Full CRUD interface
- ✅ **Filter & search** - By pipeline or status
- ✅ **Real-time stats** - Queue, sent, replied counts

## How to Use

1. Open: https://gedaliagillis.github.io/worky-dashboard/
2. Click **"+ Add Lead"** or **"Edit"** on existing leads
3. Make changes
4. Click **"Save"**
5. Dashboard auto-commits to GitHub
6. Changes live in 1-2 minutes

**That's it!** No manual GitHub editing needed.
